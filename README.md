# garage-door-site

Public landing page for a garage door repair business. Deployed via GitHub
Pages from `index.html`.

This site has a sibling project: **omeryuval**
(github.com/omerNYuval/omeryuval) — an internal trend-scanning agent
dashboard that will eventually propose/push content updates here based on
regional search-trend spikes.

Shared decisions between the two projects are tracked in that repo's
[`DECISIONS.md`](https://github.com/omerNYuval/omeryuval/blob/main/DECISIONS.md) —
check it for context before making changes that might overlap with the
agent's planned automation.
